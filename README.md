# How to Customize the Category Axis of Blazor Charts

## Overview

This sample demonstrates how to customize the category axis in Syncfusion [Blazor Chart](https://www.syncfusion.com/blazor-components/blazor-charts). The application illustrates how category-based values can be displayed and configured within a chart to improve readability and data presentation. It serves as a reference implementation for developers who need to render categorical data using the Syncfusion Blazor Chart component and modify the appearance or behavior of the chart axis.

The project is implemented as a Blazor application and focuses specifically on category-axis customization scenarios within chart visualizations.

## Key Features

- Demonstrates category-axis configuration in the Syncfusion Blazor Chart component.
- Uses category-based data for chart rendering.
- Shows chart-axis customization techniques for categorical datasets.
- Demonstrates chart rendering in a Blazor application.
- Uses Syncfusion chart components to display category-oriented information.

## Prerequisites

- Visual Studio 2022 or Visual Studio Code
- .NET SDK compatible with the project's target framework

## How to Run the Project

**Visual Studio 2022**

1. Clone or download this repository.
2. Open the solution file.
3. Restore all NuGet packages.
4. Set the application project as the startup project if required.
5. Build the solution.
6. Run the project using `Ctrl+F5`.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the project directory containing the `.csproj` file.

```bash
dotnet restore
dotnet run
```

4. Open the local application URL displayed after the application starts.
